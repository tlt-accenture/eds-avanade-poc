# cards-news

Custom **cards** block. Purpose: Bordered news cards with a tag label, title and Read more link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card: one cell with tag paragraph (optional icon + text, e.g. :news: News), title heading, and link as last paragraph. An optional leading image cell is supported.

## Supported variations

No variations.
