# hero-video-badge

Custom **hero** block. Purpose: Homepage hero with background photo, headline, intro, prompt link and a badge image that opens a video in a modal.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1 (optional): background picture. Last row: cell 1 heading/text/CTA; cell 2 badge picture plus a video link (Brightcove/YouTube embed URL) opened in a dialog.

No variations.
