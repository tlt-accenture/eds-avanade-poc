# quote-carousel

Custom **carousel** block. Purpose: Text-only quote slides with attribution; prev/next and dots only when there is more than one slide; no autoplay.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide, one cell: quotation paragraph(s), then the attribution as the last paragraph.

## Supported variations

No variations.
