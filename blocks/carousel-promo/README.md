# carousel-promo

Custom **carousel** block. Purpose: Autoplaying promotional carousel of wide image slides with an overlay text panel, peeking neighbours, dot pagination and pause.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per slide: cell 1 picture; cell 2 heading, description, optional CTA link.
