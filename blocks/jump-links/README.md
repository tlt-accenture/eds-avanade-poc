# jump-links

Custom **custom** block. Purpose: Sticky in-page anchor bar under the hero; marks the link for the section in view.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row, one cell: a bulleted list of links to in-page anchors (#our-approach ...). Each target section sets the same id in section metadata (key id). Put the block in its own section: that section becomes sticky under the header.

## Supported variations

No variations.
