# accordion

Custom **accordion** block. Purpose: Expandable items built on native details/summary; first item open.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per item: cell 1 title; cell 2 content (optional subheading, paragraphs, optional link). Default: gradient pill headers. faq option: plain rows with dividers and chevrons.
