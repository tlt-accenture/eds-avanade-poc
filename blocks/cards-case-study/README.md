# cards-case-study

Custom **cards** block. Purpose: Grid of client story cards: photo, client logo, name, description and Read more link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card: cell 1 photo; cell 2 logo picture (optional, first paragraph), client name heading, description, link as last paragraph. Text option: one cell per row (heading, paragraph, optional link as last paragraph). White rounded cards in a scroll-snap row with prev/next buttons while the row overflows.
