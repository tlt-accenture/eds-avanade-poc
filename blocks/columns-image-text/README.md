# columns-image-text

Custom **columns** block. Purpose: Two-column image beside text; image side follows cell order.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per split: an image-only cell and a text cell (heading, paragraph, optional list, CTA). Put the image first for image-left, last for image-right.

No variations.
